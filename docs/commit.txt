# Git Commit

Git Commit(커밋)은 작업 트리에서 변경된 파일들의 상태를 저장소(Repository)의 기록(히스토리)으로 남기는 스냅샷 작업입니다.

## 주요 개념
- **스테이징 영역(Staging Area / Index)**: 커밋하기 전에 `git add` 명령어로 커밋 대상 변경 사항을 준비하는 공간입니다.
- **스냅샷(Snapshot)**: 커밋은 단순한 차이점(diff)만 저장하는 것이 아니라, 특정 시점의 전체 파일 상태를 가리키는 스냅샷 형태로 저장됩니다.
- **커밋 해시(Commit Hash)**: 각 커밋은 고유한 SHA-1 해시값(예: `7a2f1b...`)을 식별자로 갖습니다.

## 주요 명령어 및 옵션
- `git commit -m "<메시지>"`: 커밋 메시지를 인라인으로 직접 작성하여 커밋을 생성합니다.
- `git commit -a -m "<메시지>"`: 추적 중인(tracked) 수정/삭제 파일들을 자동으로 스테이징하면서 커밋합니다. (신규 untracked 파일은 제외)
- `git commit --amend`: 가장 최근의 커밋 메시지를 수정하거나, 누락된 변경 사항을 이전 커밋에 덮어씁니다.
- `git log`: 생성된 커밋 히스토리 목록을 확인합니다.
