# GitHub Issues

GitHub Issue(이슈)는 프로젝트의 버그 추적, 새로운 기능 제안, 개선 작업, 아이디어 논의 등을 협업 팀원들과 함께 관리하고 기록할 수 있는 도구입니다.

## 주요 기능
- 작업 추적: 버그 리포트, 작업 할 일(To-do) 목록 관리
- 라벨(Labels): documentation, bug, enhancement 등으로 분류
- 담당자 지정(Assignees): 특정 작업의 담당자 할당
- 마일스톤(Milestone) 및 프로젝트 연동: 일정 및 진행 상황 추적
- 커밋/PR 연결: 커밋 메시지 또는 Pull Request에서 #번호(예: #1)를 언급하거나 Closes #1 등을 통해 자동 연동 및 닫기 가능
